# 蛋仔大冒险 · Egg Heist

这是部署在 nimade 仓库 `public/egg-heist/` 下的独立无广告 3D 网页小游戏，不会覆盖仓库原有 React/Vite 主应用。

## 打开方式

GitHub Pages 部署完成后访问：

https://wzh131213-dev.github.io/nimade/egg-heist/

## 操作

- 电脑：WASD / 方向键移动，E 或互动按钮偷蛋、存蛋；Shift 冲刺。
- iPad / 手机：左下虚拟摇杆移动，右下按钮互动、跳跃和冲刺。
- 把蛋带回基地后，点击“孵化宠物”；宠物会跟随玩家并自动产生金币。
- 使用金币升级移动速度。
- 进度保存在当前浏览器的 localStorage。

## 无广告承诺

游戏不接入广告 SDK、广告网络、广告追踪、激励视频或广告占位。页面只从 jsDelivr 加载 Three.js 3D 图形库；它不是广告服务。游戏不需要账号或 API Key。

## 注意

这是独立原创的核心玩法演示版本，使用程序生成的几何模型和原创 UI。当前尚未实现在线多人、跨设备云存档、复杂宠物合成或原作全部数值系统。首次加载 3D 场景需要网络访问 jsDelivr。
